# TL Develop – Website-Entwürfe

Zwei eigenständige Vorschläge für eine neue Website, jeweils als statisches HTML/CSS-Prototyp (ohne Build-Tools, direkt im Browser öffenbar).

## Varianten

- **`design-seriose-klassisch/`** – Seriös-klassisch: ruhiges Navy/Gold-Farbschema, Serif-Headlines, klare Struktur. Passend für einen vertrauensbildenden, konservativen Auftritt.
- **`design-modern-auffaellig/`** – Modern-auffällig: Dark Mode, Farbverläufe, große Typografie, Scroll-Animationen. Passend für einen auffälligen, zeitgemäßen Auftritt.

Beide Entwürfe nutzen dieselbe Seitenstruktur (Hero, Leistungen, Über uns, Vorgehen, Kontakt), damit sie sich direkt vergleichen lassen.

## Ansehen

Jede Variante ist eine eigenständige `index.html` – einfach lokal im Browser öffnen oder z. B. mit:

```
python3 -m http.server 8000
```

im Projektordner starten und `http://localhost:8000/design-seriose-klassisch/` bzw. `http://localhost:8000/design-modern-auffaellig/` aufrufen.

## Platzhalter

Da kein Zugriff auf den bestehenden Inhalt von tldevelop.de vorlag, enthalten beide Entwürfe **Platzhaltertexte** (Leistungsbeschreibungen, Über-uns-Text, Kennzahlen) sowie **Platzhalter-Kontaktdaten** (Adresse, Telefon, E-Mail, jeweils in `[eckigen Klammern]` markiert). Diese sollten vor einem Livegang durch echte Inhalte ersetzt werden.
